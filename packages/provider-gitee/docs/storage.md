# Gitee 存储

Gitee 账号作为连接，每个仓库对应一个 Tio 空间。支持第三方 OAuth 应用和带用户信息及仓库读写权限的私人令牌。OAuth 登录经 Tio 鉴权 Worker，仓库数据直接访问 Gitee API v5。

按页查询可访问的仓库，发现 `tio-*`、`<owner>.gitee.io` 和已经绑定的仓库。仓库内必须仅含一个有效的工作空间标记。创建空间会在个人账号下创建私有 `tio-<workspaceId>` 仓库。首次绑定使用仓库当前默认分支。仓库数字 ID、分支、空间和账号共同隔离副本和缓存。

编辑写入本地副本，正文预取后可离线使用，附件按需下载。Gitee 逐文件持久化，使用文件 SHA 检查更新和删除。附件与不可变分片先写，对象头最后发布。写入中断或冲突保留未确认编辑，下次同步恢复。多个文件或对象的发布可分批被其他客户端观察到。分享和删除由 Gitee 网页管理。
