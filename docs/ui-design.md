# Tio 界面设计与交互规范

本轮以用户提供的 `notion-snapshot` 八张截图为布局与交互参考。Tio 继续使用原有中性灰配色、深浅主题及中文/英文文案；截图中的 AI、协作和分享不属于本轮功能。

## 信息架构

工作空间切换 → 页面导航 → 页面操作 → 内容操作。空间不是普通文件夹：搜索、页面移动、引用和数据库关联始终限定在当前空间。顶部切换器只显示当前空间名称和展开指示，浮层提供可搜索空间列表、新建和重命名入口；不显示首字图标、设置入口或隔离说明。

桌面侧栏默认 260px，可调整至 220–400px并折叠。上方放搜索、新建、收藏和页面树，下方只保留 provider 声明的用户信息按钮，点击打开设置。页面操作收敛到单一顶栏；语言、主题、导入导出与连接管理进入分类设置。同步错误及重新授权保持可见。

普通正文内容宽度约 760px；数据库默认全宽。页面菜单可切换全宽，偏好按空间及页面保存。页面树提供菜单和移动对话框，拖拽仅作为快捷方式。

## 登录、空间选择与退出

登录页仅展示 Logo 和 GitHub 一键登录 / Token 按钮组、本机、连接本地文件夹。桌面左右布局，移动端纵向排列；未配置 OAuth 时禁用一键登录并提示使用 Token。备份导入仅在设置中提供。

主动登录先显示初始化、空间发现等加载状态，再进入列表页。顶部左侧返回、右侧身份摘要，中间显示全部空间，空列表使用居中的空间图标占位；底部新建固定可见，列表独立滚动。失败提供重试；权限失效保留主动恢复授权入口。宿主记录最近成功打开的空间并显示角标，不写入工作空间内容。刷新恢复上次空间，页面深链接优先；主动 OAuth 登录后进入列表，恢复原账号授权后恢复原空间。

所有新建入口先请求名称，再创建并打开。拒绝空白名称，提交时禁用重复提交，失败保留输入。新空间包含一个“开始 / Getting started”页面，只有简短富文本介绍和两个列表项。复杂示例仅用于文档和测试夹具。

身份由连接 binding 提供统一的 `ConnectionIdentity` 数据：provider、name、icon、可选 avatarUrl、details，以及本机数据提示能力。展示组件直接消费，不按连接类型选择图标。GitHub 使用用户接口返回的头像；无头像时使用提供方图标。核心协议不依赖 React。

设置桌面双栏、移动端分类导航。“通用”含外观和语言，“同步”含身份与同步操作、问题恢复和退出，“导入与导出”保留现有操作。回收站从设置打开，返回恢复到设置；无内容时显示带可访问名称的图标。

列表页返回和设置退出共用二次确认：清除登录信息、tio 的本机存储和 IndexedDB，未同步编辑将丢失。本机模式额外明确全部本机工作空间将删除。清理先强制结束编辑和后台同步，再关闭数据库、删除宿主数据；同源标签页同步停止并退出。失败显示重试。此流程与普通连接释放独立，不删除 GitHub 仓库或用户文件夹文件；PWA 静态应用资源继续用于离线启动。

编辑器顶栏只保留一个保存 / 同步状态图标按钮，悬停或键盘聚焦显示详细状态，异常优先展示并可点击恢复。更多菜单移除重命名、新建子页面和数据库入口；标题直接编辑、页面树和正文斜杠菜单保留对应能力。

## 页面与导航

浏览器地址采用 `#/w/:workspaceId/p/:objectId`，支持刷新及前进后退。每个空间记住上次页面。切换先保存当前修改，再激活目标；打开失败不能销毁当前编辑会话。

新建普通页面在桌面居中预览中编辑，关闭返回背景页面，展开进入主编辑区。手机对应全屏页面。新建后即持久化，关闭不等于删除。回收站恢复采用独立 runtime 指令；普通延迟 patch 不能复活已删除对象。

Modal/Sheet/记录详情建立浮层历史栈；返回只关闭最上层。桌面 Popover 与菜单由 Radix 管理焦点、碰撞与 Escape。搜索采用 cmdk。操作通知采用 Sonner，每个嵌入编辑器实例拥有独立通知 ID。

## 数据库

数据库持有多个 `databaseView`，各自保存名称、布局、筛选、排序、分组、字段显示及顺序、列宽。创建、复制、删除视图不复制记录；至少保留一个视图。整页记住选中视图，嵌入块继续绑定明确的 viewId。删除被引用视图后显示修复入口，修复更新块引用。

表格保留 Glide，使用其原生列头定位菜单，避免滚动与列宽不同步。列头提供属性编辑、筛选、升降序、移动、隐藏和删除；标题属性不能隐藏或删除。字段类型创建后不提供破坏性转换。记录详情通过侧栏打开，可展开整页；字段编辑和视图配置不再常驻在正文上方。

筛选支持 contains、eq、notEmpty，多个条件按 AND 组合；排序支持多字段。日期等值按日期值比较，空多选不视为有值。新增字段和已有视图的数据结构保持向后兼容。

## 移动与可访问性

768px 以下使用抽屉导航、全屏页面预览和记录详情，纯操作与确认浮层使用底部面板；命名、Token、搜索、属性编辑以及含文字输入的配置浮层在手机上居中。共享 Modal / Popover 的 `mobilePlacement="center"` 使用 VisualViewport 的尺寸与偏移定位，键盘弹出或页面平移时保持在可视区域内，超长内容在弹窗内部滚动。表格默认展示记录列表，可切换横向表格，不改动共享视图的布局。看板横向滚动。移动端文字编辑提供随 VisualViewport 调整位置的工具栏；真实软键盘和输入法仍须真机验收。

命名图标按钮提供可访问名称，菜单使用原生可访问原语，支持键盘和焦点恢复。颜色由共享令牌驱动；独立编辑器的样式及浮层保持在 `.tio-editor` 边界内。

## 实现与验证

宿主负责 URL、空间切换、偏好及连接；编辑器负责内容与数据库；写入通过 runtime 执行。`EditorSurface` 增加可选 `renderHeader`、`pageActions`、`onOpen`、`autoFocusTitle`，`EditorTarget` 增加可选 mode。独立宿主不传这些参数时保留默认顶栏和导航行为。

新增 `fieldOrder` 和 `columnWidths` 可选字段并校验，旧视图继续有效。组件依赖锁定在 pnpm lockfile；BlockNote 使用同版本官方 shadcn 包，移除 Mantine 适配层。

验证命令：`corepack pnpm check`、`corepack pnpm test:e2e`。专项用例覆盖空间隔离、页面预览及历史、回收站恢复、视图独立配置、手机嵌套面板和失败切换时保留草稿；原有离线、PWA、同步、备份和独立编辑器测试继续执行。
