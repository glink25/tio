# Tio 界面设计与交互规范

本轮以用户提供的 `notion-snapshot` 八张截图为布局与交互参考。Tio 继续使用原有中性灰配色、深浅主题及中文/英文文案；截图中的 AI、协作和分享不属于本轮功能。

## 信息架构

工作空间切换 → 页面导航 → 页面操作 → 内容操作。空间不是普通文件夹：搜索、页面移动、引用和数据库关联始终限定在当前空间。顶部切换器显示完整的当前空间名称、可搜索空间列表和创建/设置入口，不另设空间首页。

桌面侧栏默认 260px，可调整至 220–400px并折叠。上方放搜索、新建、收藏和页面树，下方放回收站、设置及存储状态。页面操作收敛到单一顶栏；语言、主题、导入导出与连接管理进入分类设置。同步错误及重新授权保持可见。

普通正文内容宽度约 760px；数据库默认全宽。页面菜单可切换全宽，偏好按空间及页面保存。页面树提供菜单和移动对话框，拖拽仅作为快捷方式。

## 页面与导航

浏览器地址采用 `#/w/:workspaceId/p/:objectId`，支持刷新及前进后退。每个空间记住上次页面。切换先保存当前修改，再激活目标；打开失败不能销毁当前编辑会话。

新建普通页面在桌面居中预览中编辑，关闭返回背景页面，展开进入主编辑区。手机对应全屏页面。新建后即持久化，关闭不等于删除。回收站恢复采用独立 runtime 指令；普通延迟 patch 不能复活已删除对象。

Modal/Sheet/记录详情建立浮层历史栈；返回只关闭最上层。桌面 Popover 与菜单由 Radix 管理焦点、碰撞与 Escape。搜索采用 cmdk。操作通知采用 Sonner，每个嵌入编辑器实例拥有独立通知 ID。

## 数据库

数据库持有多个 `databaseView`，各自保存名称、布局、筛选、排序、分组、字段显示及顺序、列宽。创建、复制、删除视图不复制记录；至少保留一个视图。整页记住选中视图，嵌入块继续绑定明确的 viewId。删除被引用视图后显示修复入口，修复更新块引用。

表格保留 Glide，使用其原生列头定位菜单，避免滚动与列宽不同步。列头提供属性编辑、筛选、升降序、移动、隐藏和删除；标题属性不能隐藏或删除。字段类型创建后不提供破坏性转换。记录详情通过侧栏打开，可展开整页；字段编辑和视图配置不再常驻在正文上方。

筛选支持 contains、eq、notEmpty，多个条件按 AND 组合；排序支持多字段。日期等值按日期值比较，空多选不视为有值。新增字段和已有视图的数据结构保持向后兼容。

## 移动与可访问性

768px 以下使用抽屉导航、全屏搜索和页面预览、全屏记录详情，配置浮层使用底部面板。表格默认展示记录列表，可切换横向表格，不改动共享视图的布局。看板横向滚动。移动端文字编辑提供随 VisualViewport 调整位置的工具栏；真实软键盘和输入法仍须真机验收。

命名图标按钮提供可访问名称，菜单使用原生可访问原语，支持键盘和焦点恢复。颜色由共享令牌驱动；独立编辑器的样式及浮层保持在 `.tio-editor` 边界内。

## 实现与验证

宿主负责 URL、空间切换、偏好及连接；编辑器负责内容与数据库；写入通过 runtime 执行。`EditorSurface` 增加可选 `renderHeader`、`pageActions`、`onOpen`、`autoFocusTitle`，`EditorTarget` 增加可选 mode。独立宿主不传这些参数时保留默认顶栏和导航行为。

新增 `fieldOrder` 和 `columnWidths` 可选字段并校验，旧视图继续有效。组件依赖锁定在 pnpm lockfile；BlockNote 使用同版本官方 shadcn 包，移除 Mantine 适配层。

验证命令：`corepack pnpm check`、`corepack pnpm test:e2e`。专项用例覆盖空间隔离、页面预览及历史、回收站恢复、视图独立配置、手机嵌套面板和失败切换时保留草稿；原有离线、PWA、同步、备份和独立编辑器测试继续执行。
