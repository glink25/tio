# 后续方向

当前能力见[产品约定](requirements.md)。以下事项尚未作为完整交付验证：

- 真机移动编辑、IME、内存与原生目录权限；真实 GitHub App 安装、部署及限流联调。
- 冲突恢复内容的浏览体验；删除标记与不可变分片的保留、并发读取和垃圾回收协议。
- 更完整的索引搜索、远程查询提供方及真实设备大空间性能验证；现有扫描提供方仍可能遍历整个空间。
- 原生宿主实现、公开 npm SDK 的构建产物与声明、第三方扩展分发。
- 按工作空间配置的可复用 AI 助手，复用统一功能接口；具体实现尚未确定。
- WebDAV、服务端存储及日历等新增能力按独立需求推进。

文件快照同步不提供 CRDT 实时协作保证；如需实时协作，应单独设计协议。以上方向统一遵循[0.2.0 兼容性里程碑原则](../zen.md)：正式发布 0.2.0 前，数据结构、协议和接口按全新设计，不考虑历史兼容、迁移或升级；0.2.0 及后续版本无需兼容或迁移此前数据。从 0.2.0 开始，后续变更才考虑对 0.2.0 及以后版本的兼容性、迁移和升级，具体方案届时设计，不承诺永久兼容。
