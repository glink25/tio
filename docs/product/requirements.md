# 产品约定

愿景与开发取舍以 [Tio 之禅](../zen.md) 为准，本页只记录当前产品边界。

- 阅读、编辑和数据库管理为中心；入口提供连接、空间创建/选择和备份导入，不增加宣传首页。
- 未连接入口采用黑白品牌分栏、Logo 动画与中英文轮播文案，支持深浅主题、移动布局和减少动态效果；按运行环境能力展示 GitHub、Token、本机和本地文件夹入口；不支持或未配置的入口直接隐藏，空分组不占位，仅剩单个入口时展示完整文字按钮。首页的语言和主题选择统一收纳到设置图标浮层，桌面与移动端一致；品牌背景延伸到状态栏下方，顶部控件单独避让安全区。工作空间空列表保留顶部标题和底部实心创建按钮，中间展示空收纳盒插画；回收站空列表只展示掀盖空桶插画。
- 当前一次使用一个连接，一个连接可有多个独立空间；空间是内容与分享边界，引用和关系不跨空间。
- 页面树表达父子层级，正文提及表达引用；名称可改，ID 不变。删除目标后保留失效引用。
- 交互参照 Notion，维持中性色、深浅主题、按需出现的管理操作。宿主掌握导航、语言和主题，编辑器响应宿主配置。
- 富文本、数据库表格/看板、命名视图、字段、公式、汇总、回收站及代码块已实现；App Slice 可复用文档和数据库制作小应用。
- 本地保存立即排队，副本同步使用尾随防抖。加载失败、保存失败和授权失效必须明确区分，保留可恢复输入。
- 具备副本同步能力的工作空间支持共享的“手动同步”设置：保留本地自动保存，允许当前同步完成，后续仅通过状态详情中的“立即同步”或 Ctrl/Cmd+S 同步。关闭开关恢复自动同步；本地文件夹直接保存不受影响。
- 移动端首次使用默认阅读，桌面默认编辑；阅读选择由宿主在当前浏览器统一保存，跨文档与空间复用。阅读模式下文档菜单显示铅笔，点击仍打开菜单，通过菜单切换编辑；宿主强制只读与内容权限不能被切换解除。
- 顶部状态浮层分开显示本地保存、连接与同步状态；同步使用实际进度条，总量未知时显示不定进度，不展示具体文件计数，问题文件路径可展开查看。
- Safari 主屏幕应用使用延伸到状态栏下方的全屏背景，布局控件与弹窗内容分别避让安全区，遮罩覆盖整个视口。桌面模拟不能替代真机状态栏、键盘、输入法、内存和文件权限验证。

数据与实现说明分别见[数据契约](../protocols/data-format.md)和[整体架构](../architecture/overview.md)。未来目标见[后续方向](roadmap.md)，不视为已完成能力。

## Web 加载、主题与 App Mode

页面级等待使用对应布局的骨架屏；文档骨架与阅读宽度、留白一致，数据库局部等待保持局部布局。骨架提供读屏说明并遵循减少动态效果偏好，错误继续提供重试。

主题支持浅色、深色、自动三态循环，新用户默认自动。宿主保存偏好并监听系统变化，向编辑器及 App Slice 传递实际浅／深主题。

页面含至少一个 App Slice 时，文档更多菜单可开启 App Mode；配置随文档同步，修改需要编辑权限并进入撤销历史。开启后按正文深度优先顺序只运行第一个 App Slice，隐藏标题、正文、顶部编辑栏及块工具栏。左侧导航保留原展开偏好；收起时左上角浮岛仅提供展开按钮，关闭模式须从导航树当前页面菜单操作；该关闭菜单项由编辑器提供，宿主仅放置，不为此读取正文或判断 App Slice。只读访问者保持应用模式。应用填满内容区，不响应块高度请求；所有 App Slice 移除时显示空状态并保留导航及关闭入口。预览在自身容器内展示应用模式。静态发布和 Markdown/PDF 导出保持原阅读投影。

## 工作空间删除与分享

工作空间设置的存储页按 provider 能力提供管理入口。分享仅针对已打开空间；空间列表还提供独立删除按钮，无需打开空间。未支持的操作隐藏。

设备与本地文件夹支持永久删除，不支持分享。确认说明删除范围与不可撤销性，未保存修改也会丢弃。文件夹删除包括空间目录中的全部文件，其他空间及连接目录不受影响。当前空间删除成功后返回原连接的空间列表，不自动打开其他空间；失败保留重试入口。

GitHub 的分享引导到仓库协作者管理页，删除引导到仓库设置的 Danger Zone。弹窗显示仓库名称，说明影响整个仓库及其中其他文件。操作须在 GitHub 网页完成；打开网页不表示成功，Tio 保留本地副本与现有访问状态处理。本次不提供 GitHub 本地移除、外部完成检测或协作者编辑表单。
