# 编辑器目标与验收约定

这八项要求是后续产品迭代的约束。当前实现覆盖以下编辑器核心范围，不代表复刻 Notion 的全部功能。

| 要求                   | 当前实现与验收依据                                                                                                                                                                              |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Notion 式交互与布局    | 左侧页面树、展开/折叠、拖动排序和移动层级、祖先面包屑、正文标题、块编辑、斜杠菜单、右上角页面操作菜单；支持键盘搜索和移动对话框。                                                               |
| 极简工具               | 入口只保留工作空间、文件夹和备份导入；无 SEO 文案、宣传区或落地页。正文操作收进菜单。                                                                                                           |
| 子页面、嵌套和引用     | parentId/order 表示层级，禁止循环移动；行内提及保存 workspaceId/kind/id，支持同一工作空间的页面和数据库跳转；标题实时解析，删除后保留置灰引用。                                                 |
| 黑白与深暗色           | 新会话默认深暗色；支持黑白浅色切换并记住选择，编辑器和数据库同步切换。                                                                                                                          |
| 向后兼容               | v1 数据契约、稳定 ID、可选字段增量扩展、未知对象/字段/块保留、未来版本只读、按类型逐版本迁移接口。新增数据库能力优先复用现有记录；不能承诺任意语义破坏性变更都无需迁移。                        |
| 文档归档               | 项目文档集中在 docs/；初始三份资料在 docs/.local/，根 .gitignore 已忽略该目录。当前工作目录未包含 .git，无法核验已有 Git 索引。                                                                 |
| 连续修改只同步最后一次 | 参考初始 Cent 分析资料，采用尾随防抖：最后一次编辑并持久化后静默 1 秒再同步；前台轮询不抢跑，无固定最大等待时间强制上传；执行中的新修改保留供下一次同步。手动同步立即执行，本地保存仍即时排队。 |
| 自定义名称             | 页面标题即树中名称，数据库名称及工作空间名称可编辑；稳定 ID 和文件路径保持不变。                                                                                                                |

自动验证：`corepack pnpm check`；浏览器流程：`corepack pnpm test:e2e`。测试详情和原生目录选择器、真实移动设备等尚需人工验证的边界见 [verification.md](verification.md)。数据扩展规则见 [data-format.md](data-format.md)。
