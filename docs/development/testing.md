# 测试

测试集中在私有 workspace 包 `@tio/tests`。配置、夹具、辅助脚本和产物都放在 `tests/`，根目录只转发命令。

| 命令（仓库根目录）                                                   | 用途                                                   |
| -------------------------------------------------------------------- | ------------------------------------------------------ |
| `corepack pnpm test`                                                 | 核心逻辑测试                                           |
| `corepack pnpm test:watch`                                           | 交互运行核心逻辑测试                                   |
| `corepack pnpm test:e2e`                                             | Chromium 编辑主流程（自动构建并启动服务）              |
| `corepack pnpm check`                                                | 格式、lint、边界、全部类型检查、核心逻辑测试及生产构建 |
| `corepack pnpm --filter @tio/tests exec playwright install chromium` | 安装浏览器                                             |

配置和夹具基于文件位置解析仓库路径，不依赖调用目录。在 `tests/` 内可直接执行 `test`、`test:watch`、`test:e2e`、`typecheck`；单组逻辑测试使用 `corepack pnpm --filter @tio/tests test unit/sync`。

## 长期保留范围

- 数据契约与数据库：对象身份、未知内容无损、并发合并、基本查询、字段写入校验和空间隔离。
- 运行时：统一命令、原子提交、回执去重、失败重试、外部更新保留待确认输入、统一撤销重做、关闭刷新，以及导航防循环和空间删除隔离。
- 同步与存储：同步期间新增编辑、并发冲突、附件先行、分片完整性、发布失败恢复、本地恢复日志、GitHub 发布竞争和后台调度。
- 富文本：未知块、嵌套内容、表格、代码和原子提及的编解码无损保障。

真实 Chromium 只保留以下主流程：

1. 标题与正文真实输入、保存及刷新恢复。
2. 保存失败期间继续输入，恢复后保存最新内容。
3. 多块删除与撤销。
4. 原子提及插入、删除与撤销。
5. 表格编辑保留相邻未知内容。
6. 嵌入编辑器接收外部更新，失败重试后多实例内容一致。
7. 数据库单元格提交与撤销重做。
8. 数据库外部更新保留未确认草稿，取消后呈现最新值。
9. 记录正文输入与重新打开。

生产构建保留编辑器 CSS 作用域检查；Pages 产品构建与类型检查仍纳入完整检查。

## 测试准入与临时验证

新增或扩充长期测试必须说明保护的核心风险，以及现有用例为何不足。核心缺陷优先扩充现有用例；不因每次功能调整新增专项套件，不测试第三方组件内部行为或实现细节，不维护菜单外观、文案、样式和功能组合的穷举测试，不设覆盖率目标。

自动化、静态发布、App 模式、图标封面、导入导出、分页候选等专项验证不纳入长期测试；其中通用的数据安全保障由上述核心测试承担。非核心测试不得纳入合并，也不得移入仓库归档目录、通过 skip 或默认关闭的开关长期保留。

非核心测试、排查脚本、一次性复现和验证产物统一放入 `tests/tmp/`，需要时执行 `mkdir -p tests/tmp`。该目录整体由 Git 忽略，不提交占位文件，不得强制追踪。Vitest、Playwright、TypeScript、Oxlint 和 Oxfmt 的常规检查排除该目录。临时验证按需显式执行，可使用临时配置，不为此新增长期维护的测试框架；需要纳入长期保障时先满足上述准入标准。

Vitest 缓存、Playwright 报告和失败 trace/截图仍在 `tests/.cache/`、`tests/playwright-report/`、`tests/test-results/` 的忽略目录内。测试只使用临时数据或内存仓库，不操作用户目录。

## 验证结论边界

范围缩减不表示被移除的专项已通过验证，也不应削弱生产权限或校验逻辑。如实记录本次运行结果；历史通过记录不能作为本次验收结论。

原生目录选择器/授权、真实手机 IME/键盘/内存、GitHub App 安装和线上限流需要专门环境；模拟 API 或桌面设备模拟不能替代真机与真实端点结论。
