# 工作空间 AI 助手

侧栏底部设置按钮右侧的 AI 图标打开桌面右侧栏或移动弹窗；切换页面保留会话，切换工作空间终止旧请求和待确认操作。关系图、App 模式和空页面均保留入口。界面复用 Chaty，按需加载。

## 配置与存储

设置 → AI 中管理当前空间的多套 API 配置、默认模型与附加提示词。支持 OpenAI 兼容协议（填写 API 基地址，如 `https://api.openai.com/v1`）及 Google AI Studio。配置支持图片输入、Token 上限和自定义 JSON 请求参数；测试连接会实际请求配置的端点。

配置和 Base64 遮掩的密钥保存在工作空间对象 `assistant` 中，通过统一运行时持久化，参与空间同步、备份、导出和分享。Base64 不是加密。各空间独立，不自动借用其他空间配置。AI 工具不能读取或修改这些设置；普通对象读取和上下文会排除整个 `assistant` 字段，端点错误不透传响应正文。

聊天记录及上传文件由 Chaty 保存在当前浏览器，按 Tio、连接和工作空间隔离，不随空间同步。App Slice 的授权仍使用宿主现有本地权限存储。

## 选区引用

编辑器选中文字后，桌面气泡菜单和触屏选区工具栏提供 AI 图标。点击后将选中文字及来源页面/记录、块 ID 作为独立引用加入聊天框，保留已有草稿并打开助手，不自动发送。页面预览和记录抽屉会收起，让助手可见。引用保留选择时的原文快照；模型使用 `readReferences` 读取原文与来源版本，读取时重新检查空间和页面权限，修改前仍须读取当前版本。未接入宿主回调的独立编辑器不显示此按钮。

## 操作与权限

助手默认可操作当前空间，但实际权限始终受宿主 AccessPolicy 限制。外部 Site tools 授权独立，不继承内置助手权限。

`discover`、`tio_operations` 提供工具与操作发现；`tio_read`、`tio_write` 和 `tio_result` 调用共享 `@tio/operations`。Code Mode 通过同一注册表调用，写入逐项提交，不构成整体事务。写操作必须使用稳定 requestId；不确定结果先查询原请求。确认保存仅表示 provider 本地提交完成。

支持页面与正文、数据库字段/转换/视图/记录、移动排序、搜索、删除恢复、自动化、附件，以及当前空间导入。导入使用会话上传的 Tio ZIP，保留内容 ID，ID 冲突时拒绝；不会创建空间或导入另一个空间的 AI 配置。`tio_attachment` 提供原生图片或文本读取。`tio_host` 提供上下文、导航/预览、收藏、关系图、同步、下载导出和统一撤销重做。`tio_app_permission` 使用现有 App Slice 授权存储。

删除对象、正文块、字段、附件引用，启用自动化和扩大 App Slice 权限均须确认，不能永久免确认。检查最终变更，而非仅检查工具名；正文替换及 Code Mode 也不能绕过。撤销重做先检查实际变更，涉及上述风险时确认；不能通过历史修改 API 配置。确认后再次校验空间、输入状态、权限和版本；过期确认返回结构化错误。已授权 App Slice 代码修改沿普通内容编辑路径执行。

连接授权、空间创建删除、跨空间操作和密钥管理不作为工具开放。所有持久化修改共用运行时、仓库及撤销历史，不额外建立保存队列。

## npm 接入与发布

`packages/app` 使用 npm 精确版本 `@glink25/chaty@0.3.0`，无需相邻 Cent 仓库、本地 link 或预先构建 Chaty。执行 `corepack pnpm install --frozen-lockfile` 后即可开发和构建。该版本已通过本地接入验收并获用户确认发布；新发布版本按仓库既有策略添加精确版本的 release-age 例外，不关闭其他依赖的检查。

Chaty 公开 ESM、声明及隔离样式入口，构建产物包含所需私有 agent-core 代码，消费者不依赖该私有包。后续修改在 Cent 仓库完成，通过库构建、tarball 独立消费验证后发布新版本，再更新 Tio 的精确依赖及锁文件。
