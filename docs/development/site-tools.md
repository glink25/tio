# Codex 操作 Tio Web

在支持 [Site tools](https://learn.chatgpt.com/docs/webmcp) 的 Codex 内置浏览器中打开 Tio，连接空间并编辑，然后在同一会话告诉 Codex：

> 读取当前 Tio 工作空间，为旅行计划新建一个任务数据库，添加名称、日期和完成状态，并录入三条任务。保留原文。

无需安装 Tio 专用插件、CLI 或本地服务。首次内容读取或写入时，Tio 请求当前空间的权限：读取请求可同时允许编辑；勾选“下次不再询问”才保存到 localStorage，否则仅允许当前调用。编辑包含删除内容、启用自动化和修改已授权 App Slice 的代码。设置中的“外部 AI 访问”可调整或撤销已记住的授权；权限不随空间同步或备份，多标签页会接收撤销通知。

授权按浏览器、连接身份与空间区分。网页无法可靠验证调用者是不是 Codex，因此界面统一称“外部 AI 工具”。浏览器自身的访问审查仍生效。普通 Chrome 与 Codex 内置浏览器不保证共享 IndexedDB、登录状态或文件夹权限；本阶段仅支持接续同一浏览器中的空间。

## 工具与操作

顶层 Web 宿主在活动空间注册 `tio_context`、`tio_operations`、`tio_read`、`tio_write`、`tio_result`。普通浏览器未提供 WebMCP 时继续正常编辑，操作服务按需加载。关闭或切换空间后旧工具绑定失效。

先用 `tio_operations` 发现操作，用 `tio_context` 获得当前 sessionId。读取对象返回完整原生对象和版本；写入使用该版本和稳定 requestId。结果包括确认保存的数据及新版本。工具不会直接写存储文件，也不会提供任意代码执行能力。

支持页面/正文、数据库/字段/视图/记录、软删除恢复，以及自动化定义与运行历史。正文支持当前编辑器已知结构，包括 App Slice；未知内容可原样保留。自动化新规则默认停用，显式启用不补跑历史事件，沿现有会话执行器运行；App Slice 运行权限仍由原有本地设置管理。

字段类型转换、附件上传、空间和连接管理、常驻后台、跨浏览器接续及 Claude 专项适配不在本阶段范围内。

## 提交与错误

共享服务绑定当前 runtime，复用命令、仓库、撤销与自动化事件。用户存在未确认输入时保守拒绝外部写入；对象或依赖发生并发变化时返回 conflict，重新读取后再决定修改。字段定义变更还检查已有值和规则依赖，提交期间空间发生变化时拒绝旧检查结果。

权限、冲突、非法输入、不支持、关闭、不可用、容量上限和结果未定使用结构化状态/错误码。超时不等于取消。看到 pending 或浏览器调用超时时，用相同 requestId 查询 `tio_result`；同一请求重试不重复创建。刷新后旧 sessionId 失效，应重新检查内容，不能直接用新 ID 重试结果不明的创建。

“已确认”表示 provider 本地保存完成，GitHub 远端同步与自动化派生动作另行查看。多个工具调用没有整体事务保证；文件夹仍提供可恢复发布。撤销也沿现有自动化触发语义执行。

## 验证边界

长期核心测试扩充运行时与富文本用例，保护外部入口的空间隔离、版本条件、未知内容、未确认输入、授权复查、撤销和请求去重；原有编辑器测试不足以覆盖这些无界面入口风险。WebMCP、授权界面、自动化/App Slice 组合验证仅在 `tests/tmp/` 按需执行。

本次真实 Codex 内置浏览器已验证独立探针的工具发现、异步确认弹窗和结果返回。随后访问 Tio 开发页面时，客户端报告“Work 设置中已禁用本地浏览器使用”，因此 Tio 本体的真实 Codex 联调尚未验收。隔离 Chromium 中的工具注册适配测试只证明应用行为，不替代这一真实客户端结果。
